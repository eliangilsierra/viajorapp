# Architecture Decision Records

Significant, hard-to-reverse decisions of this project, written by the Architect agent with the team
template (`templates/adr.md` in the team repository). An ADR is `Proposed` until a human accepts it by
merging its Pull Request into `develop`.

- File name: `ADR-NNNN-kebab-case-title.md`, numbers never reused.
- Sections: Status, Context, Decision, Alternatives, Consequences, Security considerations,
  Operational considerations.
- Superseding an ADR never edits its decision text; only its status line changes.
